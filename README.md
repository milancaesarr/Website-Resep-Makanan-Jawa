# Website-Resep-Makanan-Jawa
NusaJava Eats adalah website resep makanan tradisional Jawa dengan sentuhan modern yang memperkenalkan kekayaan kuliner Jawa ke dunia. Pengguna dapat menemukan resep autentik, belajar memasak hidangan khas, sekaligus mendapatkan solusi praktis melalui bumbu instan khas Jawa yang siap pakai.
